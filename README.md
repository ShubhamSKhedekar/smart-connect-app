# SmartConnect Application

SmartConnect is a contact management web application developed using Spring Boot and Spring MVC architecture. The project was built to practice backend development concepts, secure authentication, database management, and RESTful API development.

## 🚀 Tech Stack
- Java
- Spring Boot
- Spring MVC
- Spring Security
- Spring Data JPA
- Hibernate
- Thymeleaf
- MySQL
- REST APIs
- Razorpay Integration
- Maven

## ✨ Features
- Secure user authentication and authorization using Spring Security
- Contact management with complete CRUD operations
- REST APIs for efficient user interactions
- Dynamic UI rendering using Thymeleaf
- Pagination support for optimized contact listing
- Database handling using Spring Data JPA and Hibernate
- Razorpay integration for donations/payment support
- Responsive and user-friendly interface

## 📚 Learning Objectives
This project helped in understanding:
- Spring Boot application development
- MVC architecture
- Authentication & authorization
- ORM with Hibernate and JPA
- RESTful API development
- Payment gateway integration
- Database connectivity and optimization
